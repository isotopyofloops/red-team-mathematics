# Certificate A — The pentagon N₅ falsifies Theorem 3.7

**Claim.** For the five-element lattice N₅ there is a cover C with C ∈ MCov(X) but C ∉ M(X); hence the "only if" direction of Theorem 3.7 [Boyadzhiev–Georgiou–Megaritis–Sereti, *Appl. Math. Comput.* 333 (2018) 276–285] is false as printed.

**Prerequisites.** Definitions 2.1–2.6, Definition 3.3 (the cover condition), Proposition 3.1, and the statement of Theorem 3.7 of the paper. Nothing else.

## The lattice

X = {x₁, x₂, x₃, x₄, x₅} with x₁ = 0_X, x₅ = 1_X and order generated by

x₁ < x₂ < x₃ < x₅,  x₁ < x₄ < x₅,

with x₄ incomparable to both x₂ and x₃. (Mnemonic: x₂ = a, x₃ = t, x₄ = b; the pentagon 0 < a < t < 1, 0 < b < 1.) Meets and joins exist for every pair (x₂ ∧ x₄ = x₃ ∧ x₄ = x₁; x₂ ∨ x₄ = x₃ ∨ x₄ = x₅), so X is a lattice.

## The order-matrix (Definition 2.6)

Rows r₁,…,r₅ of A_X:

| | c₁ | c₂ | c₃ | c₄ | c₅ |
|---|---|---|---|---|---|
| r₁ | 1 | 2 | 2 | 2 | 2 |
| r₂ | −2 | 1 | 2 | 0 | 2 |
| r₃ | −2 | −2 | 1 | 0 | 2 |
| r₄ | −2 | 0 | 0 | 1 | 2 |
| r₅ | −2 | −2 | −2 | −2 | 1 |

## Step 1: C = {x₂, x₄} is a minimal cover (Definitions 2.1, 2.4)

*Cover:* x₂ ∨ x₄ = x₅ = 1_X and 0_X ∉ C. *Antichain:* x₂ ∥ x₄.

*Minimal:* Let D be any refinement of C (Definition 2.1). Every d ∈ D satisfies d ≤ x₂ or d ≤ x₄, and 0_X ∉ D. The only such elements of X are x₂ and x₄ themselves, so D ⊆ {x₂, x₄}. Since ⋁D = 1_X and neither element alone joins to 1_X, D = {x₂, x₄} = C. Thus C ⊆ D for every refinement D, i.e., C is minimal by Definition 2.4. So

**C ∈ MCov(X).**

## Step 2: C violates the printed condition (MC3)

Take i with j_i = 2 (the member x₂) and k = 3 (note k ∉ {2, 4}). Check the hypotheses of (MC3) as printed:

- 3 ∈ r_{j_i}(A_X) + r_k(A_X): r₂ + r₃ = (−4, −1, **3**, 0, 4). ✔ Holds — the 3 arises at column 3 as 2 + 1, i.e., because x₂ < x₃: an element **above** x₂ triggers the sum test.
- 1 ∈ r_k(A_X) + r_{j_l}(A_X) for the only other member l (j_l = 4): r₃ + r₄ = (−4, −2, **1**, **1**, 4). ✔ Holds (x₃ ∥ x₄).

(MC3) therefore demands that (C ∖ {x₂}) ∪ {x₃} = {x₃, x₄} **not** satisfy the cover condition (Definition 3.3, with m = 2, n = 5):

2·2 + 2 = 6 ∈ r₃ + r₄ + (−1)·r₅ ?

r₃ + r₄ − r₅ = (−2, 0, 3, 3, 3). **6 does not occur.** So {x₃, x₄} *satisfies* the cover condition — correctly, since x₃ ∨ x₄ = x₅. Hence (MC3) fails for the minimal cover C, i.e.

**C ∉ M(X).**

## Conclusion

C ∈ MCov(X) but C ∉ M(X): the implication "C minimal ⟹ (MC1)–(MC3)" of Theorem 3.7 is false. ∎

**Diagnosis (one line).** (M3) of Proposition 3.5 requires x_k < x_{j_i}, which by Proposition 3.1(2) is the row-*difference* test 3 ∈ r_k − r_{j_i}; the printed (MC3) uses the row-*sum* test 3 ∈ r_{j_i} + r_k, which detects comparability in either direction, so x₃ > x₂ is wrongly admitted as a replacement witness. The same substitution error occurs in (MC2).
