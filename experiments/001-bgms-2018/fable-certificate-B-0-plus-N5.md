# Certificate B — {0} ⊕ N₅ falsifies Theorem 5.2 / Algorithm 5.4

**Claim.** For the six-element lattice X below,

**dim_{Definition 2.3}(X) = 1  but  Algorithm 5.4 prints dim(X) = 0.**

**Prerequisites.** Definitions 2.1–2.6, Definition 3.3 (the cover condition), Proposition 3.1, the printed Theorem 3.7 / Algorithms 3.9 and 5.4. The true dimension is computed from Definition 2.3 alone; no theorem of the paper is used for it.

## The lattice

X = {x₁, …, x₆} with x₁ = 0_X, x₆ = 1_X and order generated by

x₁ < x₂ < x₃ < x₅ < x₆,  x₂ < x₄ < x₆,

with x₄ incomparable to x₃ and x₅. (Mnemonic: x₂ = e, x₃ = a, x₄ = b, x₅ = t; a pentagon with one extra point e inserted below everything nonzero: 0 < e < a < t < 1, e < b < 1, b ∥ a, t.) Pairwise meets and joins: x₃ ∧ x₄ = x₅ ∧ x₄ = x₂; x₃ ∨ x₄ = x₅ ∨ x₄ = x₆; all other pairs comparable. So X is a lattice.

## Part 1 — dim(X) = 1 from Definition 2.3

*Covers of X* (Definition 2.1): subsets C with 0_X ∉ C and ⋁C = x₆. Since x₂ ∨ x₃ ∨ x₅ = x₅ < x₆, every cover contains x₄ or x₆; and x₄ alone joins to x₄, so every cover contains x₆, or contains x₄ together with x₃ or x₅.

**dim(X) ≤ 1.** Let C be any finite cover. If x₆ ∈ C, then {x₆} refines C and ord({x₆}) = 0 ≤ 1. Otherwise C contains x₄ and one of x₃, x₅, so R = {x₃, x₄} refines C (x₃ ≤ x₃ ≤ x₅, x₄ ≤ x₄). Its order (Definition 2.2): x₃ ∧ x₄ = x₂ ≠ 0_X and there is no third distinct element, so ord(R) = 1. Every cover thus has a refinement of order ≤ 1.

**dim(X) ≰ 0.** Consider the cover C₀ = {x₃, x₄}. Any refinement D of C₀ consists of nonzero elements below x₃ or x₄, i.e., D ⊆ {x₂, x₃, x₄}. For ⋁D = x₆ we need x₃, x₄ ∈ D (no proper subfamily joins to x₆). But then D contains the two distinct elements x₃, x₄ with x₃ ∧ x₄ = x₂ ≠ 0_X, so ord(D) ≥ 1. Hence C₀ has no refinement of order 0, and dim(X) ≤ 0 fails by Definition 2.3(1).

Together: **dim(X) = 1** by Definition 2.3(2). ∎

*(Consistency remark, not used above: the minimal covers by Definition 2.4 are exactly {{x₃, x₄}}, with ord = 1, agreeing with Corollary 1.2.)*

## Part 2 — the published procedure prints 0

Order-matrix A_X (Definition 2.6), rows r₁,…,r₆:

| | c₁ | c₂ | c₃ | c₄ | c₅ | c₆ |
|---|---|---|---|---|---|---|
| r₁ | 1 | 2 | 2 | 2 | 2 | 2 |
| r₂ | −2 | 1 | 2 | 2 | 2 | 2 |
| r₃ | −2 | −2 | 1 | 0 | 2 | 2 |
| r₄ | −2 | −2 | 0 | 1 | 0 | 2 |
| r₅ | −2 | −2 | −2 | 0 | 1 | 2 |
| r₆ | −2 | −2 | −2 | −2 | −2 | 1 |

**Algorithm 3.9, Steps 4–7.** The incomparable pairs of X are exactly (x₃, x₄) and (x₄, x₅), so the antichains with ≥ 2 elements are {x₃, x₄} and {x₄, x₅}; there are none of size ≥ 3. Cover condition (Definition 3.3, m = 2, n = 6, test value 2·2 + 2 = 6):

- {x₃, x₄}: r₃ + r₄ − r₆ = (−2, −2, 3, 3, 4, 3); 6 ∉ ⇒ satisfies. So {x₃, x₄} ∈ A₂(X).
- {x₄, x₅}: r₄ + r₅ − r₆ = (−2, −2, 0, 3, 3, 3); 6 ∉ ⇒ satisfies. So {x₄, x₅} ∈ A₂(X).
- Singletons: {x_j} satisfies the singleton cover condition (3 ∉ r_j − r₆) iff j = 6 (for j < 6, column j of r_j − r₆ is 1 − (−2) = 3). So A₁(X) = {{x₆}}.
- A₃(X) = A₄(X) = ∅.

**Algorithm 3.9, Step 8 (the printed (MC1)–(MC3)) eliminates every candidate:**

1. **{x₃, x₄}**, at j_i = 3 with k = 5 (k ∉ {3, 4}): hypotheses — 3 ∈ r₃ + r₅ = (−4, −4, −1, 0, **3**, 4) ✔ (arising as 2 + 1 at column 5, i.e., because x₃ < x₅, an element *above* x₃); 1 ∈ r₅ + r₄ = (−4, −4, −2, **1**, **1**, 4) ✔ (x₅ ∥ x₄). Conclusion demanded: {x₄, x₅} fails the cover condition. It doesn't (above). **(MC3) violated ⇒ {x₃, x₄} ∉ M(X).**
2. **{x₄, x₅}**, at j_i = 5 with k = 3: hypotheses — 3 ∈ r₅ + r₃ ✔ (same vector as above); 1 ∈ r₃ + r₄ = (−4, −4, **1**, **1**, 2, 4) ✔ (x₃ ∥ x₄). Conclusion demanded: {x₃, x₄} fails the cover condition. It doesn't. **(MC3) violated ⇒ {x₄, x₅} ∉ M(X).**
3. **{x₆}** (the singleton candidate): here the printed specification is **incomplete**. (MC1) asks whether C ∖ {x₆} = ∅ "satisfies the cover condition," but Definition 3.3 defines that predicate only for nonempty antichains. Strictly as printed, Algorithm 3.9 is therefore *undefined* on this input — itself an additional specification defect. Since no completion is given, we branch over every executable interpretation:

   **(a) Natural completion: ∅ does not satisfy the cover condition.** Then {x₆} passes (MC1) and is tested against (MC2). Take (k₁, k₂) = (3, 4): hypotheses — 1 ∈ r₃ + r₄ = (−4, −4, **1**, **1**, 2, 4) ✔ (x₃ ∥ x₄); 3 ∈ r₆ + r₃ = (−4, −4, −1, −2, 0, **3**) ✔; 3 ∈ r₆ + r₄ = (−4, −4, −2, −1, −2, **3**) ✔; the quantifier over l ∈ {1, …, m} ∖ {i} is empty. Conclusion demanded: (∅) ∪ {x₃, x₄} = {x₃, x₄} fails the cover condition. It doesn't (above). **(MC2) violated ⇒ {x₆} ∉ M(X).** Then M(X) = ∅, Algorithm 5.4's default clause sets every d_m = 0, and Step 7 **prints dim(X) = 0**. (Theorem 5.2's L is a maximum over the empty set and is undefined; the algorithm resolves it to 0.)

   **(b) An implementation that special-cases or retains the singleton top cover.** Then M(X) ⊆ {{x₆}}. By Definition 2.2, ord({x₆}) = 0 (the meet of any 2 distinct elements is 0_X vacuously; the single element x₆ ≠ 0_X). So d₁ = 0, and d₂ = d₃ = d₄ = 0 by the default clause since M(X) contains no larger cover. Step 7 **prints dim(X) = 0**.

   **(c) No completion at all.** Algorithm 3.9 does not terminate with a defined value on this six-element non-chain input: the published procedure is under-specified — a defect, not a rescue.

In every executable interpretation the published procedure outputs **0**; in the strict literal reading it outputs nothing at all. Crucially, the genuine minimal cover {x₃, x₄} — the one carrying the true dimension — is unambiguously rejected in item 1, so no reading of the singleton edge case can recover the correct answer.

## Conclusion

**dim_{Definition 2.3}(X) = 1**

**dim_{Algorithm 5.4}(X) = 0**  *(under every executable interpretation of the singleton edge case; the strict literal specification is undefined there — see item 3)*

Theorem 5.2 and Algorithm 5.4 are false as printed. The failure is inherited from Theorem 3.7's (MC2)/(MC3): the row-sum comparability test 3 ∈ r_{j_i} + r_k admits elements above x_{j_i} as replacement witnesses, where Proposition 3.5 requires the directional test x_k < x_{j_i}, i.e., 3 ∈ r_k − r_{j_i} (Proposition 3.1(2)). ∎

## Corollary (assuming the repaired Proposition 3.5 characterization)

*This observation is **not** part of the self-contained certificate above; it additionally depends on the truth of the statement of Proposition 3.5 — that (M1)–(M3) imply minimality — whose published proof has a gap and whose repaired proof has passed hostile review within this project.*

The printed hypotheses of (MC2)/(MC3) quantify over a strictly larger witness set than (M2)/(M3), so any cover passing the printed conditions also satisfies (M1)–(M3), and is therefore minimal by Proposition 3.5. Hence M(X) ⊆ MCov(X) for every finite lattice X: the published procedure can only *under*estimate the covering dimension, never overestimate it. In particular, lower bounds on dim derived from Algorithm 5.4's output remain valid in downstream work; claimed exact values do not.
